# eulerProject1
This is practice for Euler Project problem 1. It involves obtaining the sum of multiples of 3 or 5 under 1000.

The mental workflow for this problem went like this for me:

1. Figure out that I need a nested "For loop" for counting up the number line and evaluating each number as a multiple of 3 or 5
2. Evaluation as a multiple would have to be determined by the quotient being equal to the outer "For loop" count
3. If evaluation accepts number as a multiple it should be added to the sum and stop the nested "For loop" (hence i++;)
4. I would need to experiment using 10 as a placeholder, then make adjustments once core logic was finished
